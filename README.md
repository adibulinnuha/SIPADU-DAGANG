# SIPADU-DAGANG

Integrated Market Management Information System

SIPADU-DAGANG adalah aplikasi berbasis Laravel untuk membantu digitalisasi pengelolaan administrasi retribusi dan operasional pasar.

## Fitur

- Dashboard monitoring
- Manajemen data pasar
- Input transaksi retribusi
- Verifikasi transaksi
- Generator bendel otomatis
- Rekap harian
- Export laporan Excel
- OCR e-Ticketing berbasis AI Assisted

## Teknologi

- Laravel 13
- PHP 8.3
- SQLite / MySQL
- Tailwind CSS
- Flowbite
- Laravel Breeze

## Workflow

Upload e-Ticketing → OCR → Review Operator → Transaksi Retribusi → Verifikasi → Bendel Otomatis → Laporan
